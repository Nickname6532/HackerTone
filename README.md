# 프리잡 PreJob

취업준비생을 위한 **입사 전 직무 언어 선행학습** 웹서비스 프로토타입입니다.
`prejob.html` 파일 하나로 동작합니다. 서버·설치 없이 더블클릭해서 열면 됩니다.

## 주요 기능
| 구분 | 기능 |
|---|---|
| 개인 학습 | 직무용어 사전, AI 업무문장 해석기, 상황별 퀴즈, 직급별 직무데이터 |
| 게임 훈련소 | 용어 스피드런(60초), 용어 짝맞추기, 현장 안전 훈련(2D 시나리오), 오답 집중 훈련, XP·레벨·뱃지·오늘의 미션·랭킹 |
| 커리어 | 이력서 작성(실시간 미리보기·완성도·AI 첨삭·PDF 저장), 이력서로 채용공고 지원, 지원 현황 |
| 기업 공간 | 회사 공개 페이지(소개·채용·공개 자료), 입사 인증 후 내부 학습공간(직급별 공개 자료·AI 요약·확인 퀴즈) |
| 기업 콘솔 (staff) | 구성원·직급 관리, 입사 인증(초대 코드 발급·요청 승인), 자료 등록·승인·직급별 공개 범위, AI 요약·퀴즈 검토, 채용·지원자 관리, 공개 페이지 편집, 격리 자동 검증 |
| 플랫폼 관리자 | 지표·문의·콘텐츠·기업 테넌트·사용자 관리 (비밀번호 `1234`) |

## 계정과 데이터 격리
- **개인 회원**과 **기업 담당자(staff)** 는 메뉴와 데이터가 분리되어 있습니다.
- 개인은 한 번에 한 회사에만 소속되며, 담당자가 발급한 초대 코드(이메일 일치)나 담당자 승인으로만 입사 인증됩니다.
- 내부 자료는 같은 회사 + 인증된 소속 + 회사가 정한 최소 직급 이상일 때만 보입니다. 직급은 그 회사 담당자만 바꿀 수 있습니다.
- 모든 화면은 `Policy` 함수(`canViewDoc`, `canManage`, `canViewApp`)를 거쳐 데이터를 읽고, 콘솔의 **보안·격리** 탭에서 자동 검증 결과를 볼 수 있습니다.
- 데모는 브라우저 안(localStorage)에서 동작합니다. 실제 서비스에서는 같은 규칙을 서버 API와 DB 쿼리에서 강제해야 합니다.

## 데이터 안내
알파테크·베타로지스와 그 인물·자료는 모두 가상의 샘플입니다. 연봉·통계는 시연용 더미값이고, 안전 시나리오는 실제 안전교육을 대체하지 않는 데모 초안입니다.
