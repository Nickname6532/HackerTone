# 프리잡 PreJob

**신입사원을 위한 입사 후 직무 언어 교육** 웹서비스 프로토타입입니다.
`prejob.html` 파일 하나로 동작합니다. 서버·설치 없이 더블클릭해서 열면 됩니다.

## 주요 기능
| 구분 | 기능 |
|---|---|
| 직무 학습 | 직무용어 사전(공통·마케팅·개발·영업·인사·재무·설비보전), AI 업무문장 해석기, 상황별 퀴즈 |
| 게임 훈련소 | 용어 스피드런(60초), 용어 짝맞추기, 현장 안전 훈련(2D 시나리오), 오답 집중 훈련, XP·레벨·뱃지·오늘의 미션·랭킹 |
| 우리 회사 | 회사 승인 후 열리는 사내 학습공간: 교육 자료, AI 요약, 확인 퀴즈, 학습 진도 |
| 기업 콘솔 (staff) | 직원 승인·해제, 초대 코드 발급, 교육 자료 등록·승인, AI 요약·퀴즈 검토, 감사 로그, 격리 자동 검증 |
| 플랫폼 관리자 | 지표·문의·콘텐츠·기업 테넌트·사용자 관리 (비밀번호 `1234`) |

## 계정과 데이터 격리
- **개인 회원**과 **기업 담당자(staff)** 는 메뉴와 데이터가 분리되어 있습니다.
- 직원은 회사 담당자가 발급한 초대 코드(이메일 일치)를 입력하거나, 승인 요청을 보내 담당자가 승인하면 그 회사 직원이 됩니다. 한 번에 한 회사만 이용할 수 있습니다.
- 승인된 직원은 그 회사의 **승인된 교육 자료 전체**를 볼 수 있고, 다른 회사 자료는 볼 수 없습니다. 담당자가 승인을 해제하면 바로 열람이 막힙니다.
- 모든 화면은 `Policy` 함수(`canViewDoc`, `canManage`)를 거쳐 데이터를 읽고, 콘솔의 **보안·격리** 탭에서 자동 검증 결과를 볼 수 있습니다.
- 데모는 브라우저 안(localStorage)에서 동작합니다. 실제 서비스에서는 같은 규칙을 서버 API와 DB 쿼리에서 강제해야 합니다.

## 통합한 프로젝트
- [ChaJunHo0516/jobdicc](https://github.com/ChaJunHo0516/jobdicc) (PreBridge): 회사별 학습공간, 초대 코드 인증, AI 요약·퀴즈 승인 흐름
- [wbz5zyz5jp-debug/WORK-up](https://github.com/wbz5zyz5jp-debug/WORK-up) (JOB:DICT): 설비보전 직무 데이터(용어 30개·이론 10개·퀴즈 20문제), 2D 현장 안전 시나리오 게임. 원본은 자체 작성 데모이며 전문가 검수 전입니다. 쉬운 말 풀이는 프리잡에서 추가했습니다.

## 데이터 안내
알파테크·베타로지스와 그 인물·자료는 모두 가상의 샘플입니다. 통계는 시연용 더미값이고, 안전 시나리오는 실제 안전교육을 대체하지 않는 데모 초안입니다.
